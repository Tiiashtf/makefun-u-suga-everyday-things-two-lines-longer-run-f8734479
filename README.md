A traffic jam explained to a 10-year-old in two lines: a wide river of cars trying to squeeze through one tiny drinking straw — and an honest second line about what that picture covers and what it leaves out. A single deterministic Python program writes the two lines to `/output/entry.txt` for make.fun's "Everyday Things, Two Lines, Longer Run" bounty.

## Run it
